# Data Islands

An island-hopping practice game for junior data engineering skills: Python, SQL, APIs and PostgreSQL. Each island is a portfolio project you build one level at a time.

Everything is in `index.html`, with no build step and no dependencies.

## Play it

- **On your computer:** open `index.html` in a browser.
- **From a link (GitHub Pages):** in the repository, go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then save. After a minute the game is live at `https://<your-username>.github.io/<repo-name>/`.

## Progress

Progress saves in the browser you play in. A different browser or device, a private window, or clearing site data starts fresh.
